3. Manuscript

Paste formatted Google Docs text or select text and use Bold / Italic. Formatting is stored as **bold** and *italic* markers in the manuscript.

0 words · 1 minute estimated

Export from Google Docs as Microsoft Word (.docx). Each file imports as an episode. Google Docs tabs may not export as separate files; export tabs individually if needed. Bold and italic formatting is converted into manuscript markers where supported. The Word converter loads from a third-party CDN and requires an internet connection.

4. After the episode

Poll scheduling and the author fallback are saved as metadata. The current public reader uses local demonstration voting, not a secure shared vote count. Automated branching is a later milestone.

5. Export

Story JSON is compatible with the V0.2 reader. To add a new story, upload its JSON into stories/, then merge the downloaded catalog entry into stories/catalog.json. Existing stories: merge new episodes into their story JSON instead of replacing previously published episodes.
